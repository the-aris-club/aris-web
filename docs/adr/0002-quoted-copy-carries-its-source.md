# Quoted copy carries its source, as a location in the private repo

The page quotes the club's governance documents: the Community Terms, the Member job description, the recruitment flow, the identity ADR. We moved those quotes, and the club's structural facts, into `lib/club.ts` as one module where each quoted block records the file, section and line it came from, and each section anchor is defined once and used as both the nav href and the section id.

## Considered Options

- **Leave the quotes where they are and add a comment per block.** Cheapest, and the comments would have been the third copy of the same provenance rather than the first. The four technical departments existed twice on the page with byte-identical scope lines, and the section anchors existed as ten literals for five anchors whose order already disagreed with this file. A comment says where text came from; it does not stop a second copy appearing next to the first.
- **Vendor the source documents into this repository so CI can check the quotes.** This is the only option that buys an automated gate on drift. Rejected because `the-aris-club` is private and its own documents forbid a second source of truth for a governance document, which is the exact problem `app/legal/community-terms/terms.mdx` already carries under a `ponytail:` note. A vendored copy would double that problem in exchange for a check, and the check would be the second source it was checking.
- **Cite a URL or a document name with no location.** The cheapest form of provenance and the one that was already in the tree: `hero.tsx` cited `docs/adr/0005`, which is a document about project lifecycle and safety, in a repository where it does not exist. The sentence it was citing is in `docs/adr/0001-club-identity-and-scope.md` in a repository this one does not name. Rejected because a pointer a reader cannot follow is not provenance.
- **A nightly job in the private repo that opens a pull request here.** Viable and the right shape if the club later wants an automated gate. Not taken now, because it needs a credential and a CI grant in a repository this work does not have rights to configure.

## Consequences

- **Provenance is checkable by a person or an agent and not by CI.** Every source in `lib/club.ts` was verified against `/Users/xirothedev/workspace/the-aris-club` by line number while this decision was taken. That verification is not automatic, and the module says so rather than implying a guarantee it does not provide.
- **Line numbers are a maintenance cost and a point of failure.** An upstream edit that shifts a line makes a correct citation wrong. That is acceptable: the citation is a pointer to a location, and a wrong pointer is visible to the next reader, unlike a paraphrase that reads fine. The alternative — citing the section only — was rejected because the repository is large enough that a section number alone is slow to check.
- **The module holds quoted copy and structural facts, not page voice.** Page voice arranges the club's facts into an order a reader can follow and may introduce no number, boundary, promise or prohibition the club has not already stated, per this repository's own rule. Moving it into the module would make that module a content management system rather than a place the club's own commitments live. The practical consequence is that some strings on the page are still local to the section that speaks them, deliberately.
- **Counts are derived where the copy asserts a count.** The Automation lede says "Eight decisions" because `BOT_RESERVED_DECISIONS.items.length` is eight, and the CTA's "Three evaluators" reads `RECRUITMENT.evaluatorsMinimum`. A quoted list that changes length no longer leaves the prose claiming a number its own data does not support.
- **`apps/web/lib/club.test.ts` is the first test in this repository** and runs on `node --test` with no test dependency. There is still no `test` script, no turbo task and no CI step, which is deliberate at one test file: see ADR-0003 for why.
- **One divergence from the source is declared rather than hidden.** The Community Terms say "MSSV"; the page says "Student ID". `NEVER_SENT_TO_AI` carries that divergence and names the fix that belongs upstream, so re-syncing the copy does not silently reintroduce it without anyone seeing the rule.

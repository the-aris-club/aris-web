# Keep the existing layout, replace only the content

The page keeps the layout, section order, class names and animations it already had, and only the content changed: text, figures, images, links, metadata.

The obvious alternative was to restructure the page around the club's actual material, which would have produced a shorter and more coherent set of sections. That was tried and reverted. The existing layout is the thing being kept, and a rewrite discards it while looking like an improvement.

Two sections were removed rather than filled: the live activity feed, because the club has run no activities and a counter cannot be honestly populated, and pricing, because the charter forbids collecting fees or sponsorship until the authority confirms the club's right to and no figure exists anywhere. Every other section kept its frame, including the bento proportions, the scroll-stacked cards, the auto-advancing panel and the marquee, which now carry house facts and real capabilities instead of invented metrics.

A layout that no longer fits its content is a content problem to solve by changing content. If a section is removed again, the reason belongs in `docs/brand-rollout.md`.
